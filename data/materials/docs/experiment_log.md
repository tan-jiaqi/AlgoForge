# 流失模型实验记录（数据科学组）

| 日期 | 方案 | 验证集指标 | 结论 |
| --- | --- | --- | --- |
| 2024-02-20 | 缺失填补 + one-hot + 标准化 + 逻辑回归 | AUC 0.82, recall 0.71 | 基线，可解释性好，召回略低于要求 |
| 2024-02-27 | 缺失填补 + one-hot + 随机森林 | AUC 0.83, recall 0.66 | 默认阈值下召回偏低 |
| 2024-03-05 | 缺失填补 + one-hot + LightGBM（class_weight=balanced） | AUC 0.85, recall 0.78 | 最优，满足召回要求，可输出特征重要性 |
| 2024-03-12 | LightGBM + 全量数据目标编码 region | AUC 0.97 | **作废**：目标编码泄漏标签，上线后 AUC 跌至 0.71 |
| 2024-03-19 | LightGBM + 在网时长分段 + 消费比值特征 | AUC 0.86, recall 0.80 | 特征工程带来小幅提升 |

备注：
- 所有实验均为 5 折分层交叉验证，随机种子 42。
- 逻辑回归在加 class_weight=balanced 后召回可提升到 0.76，但 AUC 不变。
